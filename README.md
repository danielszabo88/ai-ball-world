# ai-ball-world

> *A simulation of autonomous agents that think, remember, feel, and decide. Built from scratch in vanilla JavaScript, one concept at a time.*
>
| Episode | Title | Concept |
|---|---|---|
| S01E01 | Say Hello | Conversation lifecycle, message system, cooldowns |
| S01E02 | Social Energy | Internal state, motivation, decision-making |
| S01E03 | Relationships | Social graph, discovery, relationship values |
| S01E04 | Memory | Memory objects, recency decay, relationship calculation |
| S01E05 | Resources | Hunger, food, competing needs |
| S01E06 | Decisions | Utility-based scoring, quadratic urgency curves |
| S01E07 | Perception | Vision radius, limited information, target persistence |
| S01E08 | Personalities | Behavioral modifiers, partner selection, rejection |
| S01E09 | Emotions | Stress, satisfaction, frustration, emotional feedback loops |
| S01E10 | Goals & Plans | Goal-task-plan architecture, planner system |
| S01E11 | The Handshake | Conversation fully integrated into planner, frozen state |
| S01E12 | Inspector | Pause/speed controls, event log, live agent inspector |
